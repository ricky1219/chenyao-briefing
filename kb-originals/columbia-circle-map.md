# 上生·新所新园区地图详解

> 来源：商业咔 | ima同步：2026-06-30

---

上生·新所在二期开放半年后推出新版园区地图，凭借细节和巧思在小红书刷屏。

## 设计理念

二期地图在保持一期立体质感的基础上，增加了更多设计巧思——"类似的基底，不同的逻辑"。地图没有事无巨细地显示每个商户落位，而是**突出标志性建筑/空间**，帮助客人最快找到目的地。这是基于用户体验和直觉思维的设计。

## 各建筑设计元素对照

| 建筑/空间 | 地图设计来源 |
|-----------|------------|
| 喷泉广场 | 水元素，唯一有内容填充的广场 |
| 海军俱乐部 | 建筑外墙花窗造型直接"复制粘贴" |
| 附属泳池 | 马赛克元素 + 颜色拼接勾勒泳池造型 |
| 茑屋书店 | 标志性门洞，打卡最多点位之一 |
| 香樟广场 | 因种植香樟树得名 |
| 玉兰广场 | 因玉兰树得名，偏休闲职能 |
| 城市地毯 | 9号楼另一侧大型活动空间，"够平" |
| 10号楼 | "魔方"结构造型，二期代表性新建建筑 |
| 15、16号楼 | 两种代表性外墙饰面，构成"都市森林"外围 |
| 蕨类花园 | "都市森林"区域的正式命名 |
| 12号楼 | 水景景观装置，加入镭射元素 |
| 迷宫花园 | 与金地新华道衔接区域 |
| 17号楼 | 红色集装箱风格元素 |
| 孙科别墅 | 三个尖顶门洞标志 |

## 动线逻辑

在开放式街区中，动线相对模糊。项目选择**记相对位置、找楼或广场**而非记路线——"前面这栋楼的背面""茑屋书店的对面"比路名更实用。立体地图的形态更容易通过直觉关联建筑特征到达目标店铺。

## 借鉴价值

立体地图并不少见，但上生·新所的看点在于对历史/新建建筑不同元素的**灵活运用及输出**——这一思考逻辑比地图形式本身更值得借鉴。
